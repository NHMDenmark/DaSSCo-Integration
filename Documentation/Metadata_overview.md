The fields in the issue object: - category : this is the overall category for the issue and belongs to a defined list of values - name : the name of the issue, this can be anything but should aim to be short and descriptive - timestamp : the timestamp for when the issue was noted - status : the assets status when the issue was discovered - description : the description of the issue - note : any further information about the issue that isnt covered by description - solved : flag noting if the issue has been taken care of, it is not a problem to have unsolved issues | Processing pipeline when issues are discovered.
