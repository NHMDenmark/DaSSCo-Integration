## "asset_guid"

**Data type:**  
String  

**Value:**  
Example: "7e8-6-0a-08-32-39-0-002-03-000-048fe2-00000" or "7e8-6-0a-08-32-39-0-002-03-000-048fe2-00000_72".

**Description of metadata field:**  
This is the unique id generated for each asset and is generated before incorporation into the storage system. Parts of the string are defined based on things such as the workstation, institution and date, the other parts are randomly generated. This is to enable a unique name for each asset.Derivatives can be recognized by ending with _72 or _400. 

**Populated by whom and when:**  
Ingestion server after receiving initial data via ingestion client. HPC scripts when creating a derivative.

**Updated where and when:**  
Never

**Generated by:**  
Ingestion server or pipeline (hpc scripts). ARS (future if assets come from specify)

**Maps to in ARS:**  
asset_guid

**Maps to in Specify:**  
None

**Notes and issues:**  
How would this be populated when coming from Specify. How would this be populated if an asset was created manually.
