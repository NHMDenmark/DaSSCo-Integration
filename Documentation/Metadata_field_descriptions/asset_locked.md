## "asset_locked"

**Data type:**  
Boolean  

**Value:**  
True, False - default is False.

**Description of metadata field:**  
Boolean that lets us control if an assets files can be changed(synced with ERDA). A locked asset can not have its files changed. A locked asset can be created/synced with specify. An unlocked asset can have its files updated in ARS/ERDA. Used by ARS to determine if the asset is ready for syncing with Specify.

**Populated by whom and when:**  
Set to false when asset is created by ARS.  

**Updated where and when:**  
Updated in ARS. When has not been decided.  

**Generated by:**  
ARS

**Maps to in ARS:**  
asset_locked

**Maps to in Specify:**  
None
