## "asset_updated_by"

**Data type:**  
String  

**Value:**  
Username (both service users and human users) or null.

**Description of metadata field:**  
User that last updated the asset  files. This is the user from keycloak which could include a service user, e.g. processing script.Update include the deletion of files as long not all files are deleted. Update includes adding files to an asset as long as its not the initial addition of files. 

**Populated by whom and when:**  
ARS populates this field when media files are changed, and the change has been persisted in ERDA.

**Updated where and when:**  
When asset files are changed/have changes made to them and the change has been persisted in ERDA.

**Generated by:**  
ARS

**Maps to in ARS:**  
"asset_updated_by" and partly the event user for UPDATE_ASSET event.

**Maps to in Specify:**  
None

**Notes and issues:**  
The field does not exist in ARS. It should be used as the user in the event protocol if we implement updating the media as part of that. BS: Maybe this is not MVP, but lets just geet an estimate
