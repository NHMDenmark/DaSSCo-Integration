## "date_asset_finalised"

**Data type:**  
String  

**Value:**  
Timestamp of the type: ISO 8601:YYYY-MM-DDThh:mm:ssZ or null.

**Description of metadata field:**  
The date when an asset was finalised (the asset_locked metadata field should change to true at same time). Finalised means that all processing has been completed and that the asset cannot be changed at all, but the metadata still can. The idea would be that a cited asset can be completely frozen.Not currently being used. Default value should be null.

**Populated by whom and when:**  
Ingestion server defaults to null.

**Updated where and when:**  
User request this after citing most likely. By a user in ARS.

**Generated by:**  
ARS

**Maps to in ARS:**  
"date_asset_finalised" 

**Maps to in Specify:**  
None

**Notes and issues:**  
Needs to correspond with some event in the ARS event protocol. Also needs some protocol on our side to determine if a copy is needed for. Considering deleting this field.Postponed decisions for what will happen with this field (07/02/25).
