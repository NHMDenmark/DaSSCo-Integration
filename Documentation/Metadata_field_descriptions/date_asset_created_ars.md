## "date_asset_created_ars"

**Data type:**  
String  

**Value:**  
Timestamp of the type: ISO 8601:YYYY-MM-DDThh:mm:ssZ or null.

**Description of metadata field:**  
The timestamp of  the initial sync with ERDA. A file is considered created when it has been successfully synced with ERDA. Alone uploading a file to an asset file share is is not an action that gets persisted or has any lasting effect on an asset.

**Populated by whom and when:**  
Populated by ARS when the asset first had media files added that was added to  ARS synced with ERDA.

**Updated where and when:**  
Never.

**Generated by:**  
ARS

**Maps to in ARS:**  
"date_asset_created_ars" and timestamp in event protocol for CREATE_ASSET.

**Maps to in Specify:**  
None

**Notes and issues:**  
None.
