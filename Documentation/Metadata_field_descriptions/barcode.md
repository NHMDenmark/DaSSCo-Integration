## "barcode"

**Data type:**  
List of strings

**Value:**  
Digit code that can be prefaced by the institution. The institution string is NOT part of the encoded digit code.Fx NHMD00929517

**Description of metadata field:**  
This refers to a physical barcode on the specimen. It is the specimen number and links to the physical object and its Specify record. Combined with institution and collection. It is part of an ID unique to that specimen and consisting of: An institution acronym, a collection acronym, and the barcode. We can have one specimen barcode related to multiple assets and in some cases one asset with multiple specimen barcodes (an example of the later is a multispecimen herbarium sheet)."

**Populated by whom and when:**  
Integration server when running pipeline or ARS when sync with Specify.

**Updated where and when:**  
If an error is discovered during auditing or processing. This will likely be handled manually by a user in in the dassco ui.

**Generated by:**  
Pipeline process(barcode reader), Specify.

**Maps to in ARS:**  
Each entry in the list maps to a "barcode" field in the specimens protocol

**Maps to in Specify:**  
Catalog Number

**Notes and issues:**  
None.
