## "specify_attachment_title"

**Data type:**  
String

**Value:**  
Example: "Image."

**Description of metadata field:**  
This maps directly to the specify field "title". It will usually contain the asset_subject and asset_payload with "of" between them. This is the temporary title for an attachment. Once syncing from specify to ARS happens this will change to include the specimen taxonomy name.

**Populated by whom and when:**  
Integration server when an asset is determined to become a specify attachment.

**Updated where and when:**  
When specify sync with ARS if the specimen the attachment belongs to has taxonomy names then the title should be updated by ARS to reflect this and then resync with specify.

**Generated by:**  
Integration server.

**Maps to in ARS:**  
None

**Maps to in Specify:**  
None

**Notes and issues:**  
We have not decided exactly how this will look.
The syncing from specify to ARS will come later so the initial title created by the integration server is currently the permanent temporary title.
