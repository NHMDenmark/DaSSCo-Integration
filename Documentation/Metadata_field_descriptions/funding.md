## "funding"

**Data type:**  
List of strings

**Value:**  
Example: "Dassco Tranche 1"

**Description of metadata field:**  
A list of entities that helped fund the processing of the asset in some way. This is used for reporting on and citing.

**Populated by whom and when:**  
Ingestion server when metadata is first created.

**Updated where and when:**  
This is editable in case of retrospectively fixes or additional sponsors if an asset needs to go through further processing. Updates can happen manually through the dassco ui or via the integration server running pipeline processes.

**Generated by:**  
Ingestion server.

**Maps to in Specify:**  
None

None.
