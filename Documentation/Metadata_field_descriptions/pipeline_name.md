## "pipeline_name"

**Data type:**  
String  

**Value:**  
8 characters followed by 4 digits. Example: PIPEHERB0001

**Description of metadata field:**  
The name of the pipeline. A pipeline is the full flow an asset goes through from digitisation to its final state (most likely published).This determines the processing jobs an asset will run through.This is a required field for creating an asset in ARS. Multiple pipelines can be added in ARS through the event protocol. The original pipeline will be filled in the pipeline_name and corresponding pipeline field.

**Populated by whom and when:**  
Ingestion server when creating the metadata.

**Updated where and when:**  
Never

**Generated by:**  
Ingestion server.

**Maps to in ARS:**  
pipeline

**Maps to in Specify:**  
None

**Notes and issues:**  
ARS calls this field "pipeline".
