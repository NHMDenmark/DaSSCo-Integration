## "workstation_name"

**Data type:**  
String  

**Value:**  
8 characters followed by 4 digits. Fx "WORKHERB0001"

**Description of metadata field:**  
This is the name of the workstation used to do the imaging. Details of the technical set up (e.g., hardware and software) should be recorded for each workstation name as a record. Updates to these should result in a change in the name of the workstation.Tells us which workstation an asset was originally created on. Can monitor digitisation, trouble shoot and retrieve technical details associated with the workstation and images.

**Populated by whom and when:**  
Populated by ingestion server or when an assets metadata is first created.

**Updated where and when:**  
Never.

**Generated by:**  
Ingestion server.

**Maps to in ARS:**  
workstation

**Maps to in Specify:**  
None

**Notes and issues:**  
ARS calls this field "workstation". Ingestion and integration server calls it "workstation_name".
