## "mos_id"

**Data type:**  
String

**Value:**  
Combined unique id based on workstation name, date of imaging and the mos barcode. Example: "WORKHERB0001_20032022_MOS 174"

**Description of metadata field:**  
Id binding multi object specimens together. This is relevant when a specimen is in multiple parts across multiple assets. Each asset has its own barcode but this id lets us identify them as a whole.When digitisers use the digi app to input data and a MOS is found the entry and the other part of the MOS is set to be part of a container with a unique name ("container name" in specify). This id will overwrite the value created by the integration server when a sync with specify happens.

**Populated by whom and when:**  
Integration server when receiving the barcode results denoting the asset as a MOS. 

**Updated where and when:**  
When syncing with specify if the asset is part of a container, the container name will be synced to be the mos_id.

**Generated by:**  
Integration server and specify.

**Maps to in ARS:**  
"mos_id"

**Maps to in Specify:**  
container id(?)
