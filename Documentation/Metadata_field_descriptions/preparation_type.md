## "preparation_type"

**Data type:**  
List of strings

**Value:**  
Examples: "sheet", "pinned", "dry", "slide" (and more will be added as the project progresses).

**Description of metadata field:**  
This shows the way the specimen has been prepared (e.g., a pinned insect or mounted on a slide). It is possible for a specimen to contain multiple preparation types. Example: DNA sample from a pinned insect.

**Populated by whom and when:**  
Integration server when running pipeline processes.

**Updated where and when:**  
If an error is discovered during auditing or processing. This will likely be handled manually by a user in in the dassco ui.

**Generated by:**  
Ingestion server when creating the metadata based on the input in the ingestion client.

**Maps to in ARS:**  
"preparation_type" in the specimen protocol.

**Maps to in Specify:**  
None[Not in attachments record, but in specimen catalogue record - something to think about for the future - low priority]

**Notes and issues:**  
None
