## "digitiser"

**Data type:**  
String  

**Value:**  
Name of the digitiser, example: "Bo", "Marianne"

**Description of metadata field:**  
This is the name of the person who created the original asset (e.g., the name of the person who imaged the original specimen). For mass digitisation, this is filled in via the Ingestion Client. In case of multiple digitisers cooperating to create an asset they must agree to have a main digitiser appointed that goes into this field. The others will be added to the "complete_digitiser_list" field. All receive equal credit for the process.

**Populated by whom and when:**  
Input comes from the digitiser when using the ingestion client, and the field gets populated when the asset has its initial metadata created by the ingestion server.

**Updated where and when:**  
If an error is discovered during auditing or processing. This will likely be handled manually by a user in in the dassco ui.

**Generated by:**  
Ingestion server.

**Maps to in ARS:**  
"digitiser"

**Maps to in Specify:**  
Most likely the "credit" field. TBD.

**Notes and issues:**  
None.
